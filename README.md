## Завдання 1. Оптимізація виробництва (PuLP)

Модель ЛП:
- Змінні: `Lemonade >= 0`, `FruitJuice >= 0` (цілі).
- Ціль: максимізувати `Lemonade + FruitJuice`.
- Обмеження ресурсів:
  - Вода: `2*Lemonade + 1*FruitJuice <= 100`
  - Цукор: `Lemonade <= 50`
  - Лимонний сік: `Lemonade <= 30`
  - Фруктове пюре: `2*FruitJuice <= 40` (тобто `FruitJuice <= 20`)

Результат:
- Оптимальний план: **Lemonade = 30**, **FruitJuice = 20**
- Загальний випуск: **50**

Логіка результату проста: `FruitJuice` зверху обмежений пюре (макс 20), а `Lemonade` — лимонним соком (макс 30). Води та цукру достатньо, тож вони не є “вузьким місцем”.

## Завдання 2. Обчислення інтеграла методом Монте-Карло

Обчислити визначений інтеграл функції **f(x) = x^2** на інтервалі **[0, 2]** методом Монте-Карло та порівняти результат з аналітичним розв'язком і результатом функції `scipy.integrate.quad`.


## Реалізація

### Метод Монте-Карло

Алгоритм заснований на генерації випадкових точок:

1. Генеруємо N випадкових значень x у інтервалі [a, b]
2. Обчислюємо f(x) для кожного x
3. Інтеграл ≈ (b - a) × середнє(f(x))

---

### Аналітичний розв'язок

Для функції f(x) = x^2:

```
[x³/3]₀^2 = 2^3/3 - 0^3/3 = 8/3 ≈ 2.6666666667
```

---

## Результати обчислень

| Метод | Результат | Похибка |
|-------|-----------|---------|
| **Аналітичний** | 2.6666666667 | 0.0000% (еталон) |
| **SciPy quad** | 2.6666666667 | ~0.0000% |
| **Монте-Карло** (1,000,000 точок) | 2.6689548242 | 0.0858% |

---

## Практичне застосування

Метод Монте-Карло особливо корисний коли:
- Функція складна для аналітичного інтегрування
- Потрібен багатовимірний інтеграл
- Потрібна лише приблизна оцінка
- Немає доступу до спеціалізованих бібліотек

---

## Загальний висновок

Метод Монте-Карло **успішно обчислює визначений інтеграл** функції f(x) = x² на інтервалі [0, 2]. При використанні 1 мільйона точок отримано точність 0.086%, що є цілком прийнятним для більшості практичних застосувань. 

Порівняння з аналітичним розв'язком (8/3) та результатом функції `scipy.integrate.quad` підтверджує **правильність реалізації** методу Монте-Карло.

**Основний висновок**: Метод Монте-Карло є ефективним інструментом для обчислення інтегралів, особливо коли аналітичні методи важко застосувати або недоступні.
